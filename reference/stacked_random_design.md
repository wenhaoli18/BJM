# Random-effects design stacked across biomarkers

Like
[`random_effects_design()`](https://wenhaoli18.github.io/BJM/reference/random_effects_design.md),
but a biomarker may contribute no rows (its block is then empty and its
random effects simply do not enter).

## Usage

``` r
stacked_random_design(rows, long_sub_random)
```
