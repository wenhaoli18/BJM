# A prediction-ready fit from Rubin's-rules point estimates

Helper for
[`poolLongitudinalSub()`](https://wenhaoli18.github.io/BJM/reference/poolLongitudinalSub.md):
see its `long_fit_all` return element.

## Usage

``` r
pooled_longitudinal_fit(long_fit_all_list, pooled)
```

## Arguments

- long_fit_all_list:

  The completed-data fits.

- pooled:

  [`poolLongitudinalSub()`](https://wenhaoli18.github.io/BJM/reference/poolLongitudinalSub.md)'s
  per-outcome pooled tables.

## Value

A `longitudinalSub.BJM` object.
