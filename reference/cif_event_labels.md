# Legend labels for the event types in cifPlot()

Legend labels for the event types in cifPlot()

## Usage

``` r
cif_event_labels(event_values, event_labels)
```

## Arguments

- event_values:

  Sorted event type values, as character.

- event_labels:

  The user's `event_labels` argument.

## Value

A character vector of labels, one per event type.
