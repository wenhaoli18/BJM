# Print a fitImputedBJM fit

A short summary of a
[`fitImputedBJM`](https://wenhaoli18.github.io/BJM/reference/fitImputedBJM.md)
fit: the imputation settings and the longitudinal sub-model's fixed
effects (pooled over the imputations, with the fraction of missing
information).

## Usage

``` r
# S3 method for class 'fitImputedBJM'
print(x, digits = 4, ...)
```

## Arguments

- x:

  A `"fitImputedBJM"` object.

- digits:

  Number of significant digits.

- ...:

  Not used.

## Value

`x`, invisibly.
